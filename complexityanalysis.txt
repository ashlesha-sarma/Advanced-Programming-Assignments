Complexity Analysis for Activity Log Analyzer

Question 1: Time Complexity for Computing Top K Users

Function: `most_active_users(logs, k)`

Let:
n = number of log entries
u= number of unique users
k = number of top users required

First, the function calculates the total time spent by each user by going through all log entries once. This takes O(n) time.
Next, the users are sorted based on their total time. Sorting u users takes O(u log u) time.
Finally, the program selects the top k users from the sorted list, which takes **O(k)** time.

Overall Time Complexity:
O(n + u log u)

Question 2: Space Complexity of Storing Intermediate Results

The program stores the total time of each user in a dictionary. Since one entry is stored for each unique user, this requires O(u) space.
It also creates a sorted list of users which again stores u elements. The final result list stores only k users.

Since k ≤ u, the total space used is mainly due to storing unique users.

Overall Space Complexity:
O(u)
