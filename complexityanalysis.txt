Complexity Analysis

Question 1: Time complexity of computing course averages

Method:`getAverageScorePerCourse(List<Student> students)`

Let:
S = number of students
C_avg = average number of courses per student
C_unique = number of unique courses

The method goes through every student and then through all the courses of that student. For each course score, a HashMap operation is used to update the total score, which takes constant time on average.

After processing all students, the program creates the final map of course averages.

Time Complexity:
O(S × C_avg)

Space Complexity:
O(C_unique) because we store course totals in a HashMap.

Question 2: Complexity of sorting top N students

Method: `getTopNStudents(List<Student> students, int n)`

Let:
S= number of students
C_avg = average number of courses per student
N= number of top students required

The method sorts all students based on their average scores. Sorting S students takes O(S log S) time. During sorting, the program calculates the average score of students, which requires checking all their courses.

Because of this, each comparison takes O(C_avg) time.

Time Complexity:
O(S × C_avg × log S)
After sorting, the program simply selects the top N students.
Space Complexity:
O(N) for storing the top students.

Summary
Computing course averages: O(S × C_avg)
Sorting top N students: O(S × C_avg × log S)
where S = number of students
C_avg = average number of courses per student
